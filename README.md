# NutriScan – AI-Based Food Health Analyzer

## 📱 Project Overview

NutriScan is an Android application developed using Jetpack Compose that helps users evaluate the healthiness of packaged food products.

The application uses Optical Character Recognition (OCR) to extract ingredients from product labels and sends the extracted text to the Gemini API for intelligent analysis. The system returns a health score along with a detailed description of the product’s nutritional quality.

---

## 🚀 Features

* 📸 Capture or select food label images
* 🔍 OCR-based ingredient extraction
* 🤖 AI-powered analysis using Gemini API
* 📊 Health score generation
* 📜 History of previous scans
* 👥 Community review section

---

## 🛠️ Technologies Used

* Kotlin
* Jetpack Compose (Declarative UI Toolkit)
* OCR (Optical Character Recognition)
* Gemini API (Artificial Intelligence Service)
* Android Studio (Integrated Development Environment)

---

## ⚙️ How It Works

1. User captures or selects an image
2. OCR extracts ingredient text
3. Extracted data is sent to Gemini API
4. API analyzes and returns:

   * Health score
   * Description
5. Results are displayed to the user

---

## 🎯 Objective

To help users make informed and healthier food choices using AI-driven analysis.

---

## ⚠️ Limitations

* Depends on image quality for OCR accuracy
* Requires internet for API communication
